# Agent 体验中心

一个页面集中展示工业与企业应用，提供业务说明、操作指引、可操作工作台和多屏体验。Docker 中一个容器同时运行展示中心及 8 个子应用，按功能组织为 7 个可操作 Agent 和 1 个设备运维方案。

| Agent | 主要功能 |
| --- | --- |
| 企业 AI 成熟度诊断 | 问卷、评分、雷达图、改善建议及报告导出 |
| 经营决策优化 | 数学模型求解、库存齐套、订单承诺与优先级分析 |
| 单据识别与录入 | PDF 文字提取、人工修正、Excel／Word 导出 |
| 商品报价校验 | 消息字段检查、价格比较与产品库处理 |
| 库存配料优化 | 库存与质量约束下的配料计算及 CSV 导出 |
| 分子量复配分析 | GPC、黏度法及复配计算 |
| 能耗与设备诊断 | 模拟工况、模型训练、能耗误差及风险分析 |
| 设备远程运维 | 数据接入、设备监控与试点交付的方案说明 |

## 从 GitHub 启动

安装 Git、Docker Engine 和 Docker Compose v2，使用有权限的 GitHub 账号克隆私有仓库：

```bash
git clone https://github.com/LIYIKANG/industrial-ai-showcase.git
cd industrial-ai-showcase
docker compose up -d --build --wait --wait-timeout 240
```

打开 <http://127.0.0.1:18080/#overview>，进入 Agent 的操作指引，再打开工作台。首次构建需联网下载基础镜像及依赖。

```bash
# 查看运行状态
docker compose ps
# 停止；保留已保存的业务数据
docker compose down
```

当前实测平台是 Linux ARM64。Intel／AMD 服务器可从本仓库构建其本机架构镜像，仍需在目标环境验证。

## 服务器访问与数据

- 默认仅绑定 `127.0.0.1:18080–18088`；`18080` 是展示中心，其余端口供内嵌子应用使用。服务器上启动后仍需配置客户访问入口；仅开放 `18080` 无法完整使用全部子应用。
- 当前为内部演示版本，尚未实现统一公网登录和完整业务数据脱敏。仓库保留原业务种子、资料及部分原录像，应保持私有。详见 [客户信息脱敏清单](docs/客户信息脱敏清单.md)。
- 默认示例无需云端密钥。自由文本 AI 建模等功能需单独配置 Ollama 或云端模型；模型权重不包含在仓库中。
- 可选模型配置参照 `docker/env.example`，复制为根目录 `.env` 后自行填写。真实密钥、私有配置不提交 Git。
- Docker 使用命名数据卷持久化业务数据；Git 克隆不包含本机运行数据，迁移现有记录需另行备份和恢复数据卷。
- 仓库包含源码、Docker 构建配置和演示所需种子；不包含 `.venv`、运行日志、当前数据库及大型 Docker 镜像归档。需要离线包时可按部署文档在本机生成。
