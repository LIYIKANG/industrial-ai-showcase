# Agent 功能改版与验收

版本：1.1.0。检查日期：2026-09-17。运行环境：本机 Chrome、Docker Linux ARM64。项目目录：桌面“项目演示中心”。

## 最终页面

- 功能总览：6 个可操作 Agent，设备远程运维保留为方案。
- 7 个独立指引页：业务出发点、目标产出、准备条件、4 个操作步骤及预期结果。
- 6 个独立工作台：真实系统嵌入、手动步骤进度、可收起指引、展开、独立打开。
- 单据 Agent 内的 Excel / Word 两个版本分别保存页面与步骤状态。
- 多屏体验：4 个可操作窗口；切换窗口中的 Agent 后保留原有输入。
- 指定样例下载：不再列出全部原始客户附件与会议录像。

入口：`http://127.0.0.1:18080/`。例如单据指引为 `/#agent/document`，操作页为 `/#work/document`。

## 代码检查与修复

检查范围包括功能目录与服务归属、启动与下载路由、前端路由／页面生命周期、步骤状态、窗口切换、加载失败处理、PDF 导出链路，以及优化模型编辑到求解的调用链。已完成 Python 语法解析、JavaScript 语法检查和目录引用一致性检查。

| 问题 | 修改 | 验证依据 |
| --- | --- | --- |
| 原客户分类把不相关能力放在一起，指引和操作混杂 | 按功能拆为 Agent；介绍页与操作页分开，操作时保留步骤 | 逐一打开 7 个指引页，检查目的、准备、步骤、预期结果 |
| 窄屏 PDF 把识别面板排在上传面板之前 | 保留“先上传、后识别”的顺序 | 浏览器检查面板坐标及页面截图 |
| PDF 修改字段后直接下载可能下载旧文件 | Excel / Word 下载检查修改状态，先重新校验生成文件；处理中避免重复操作 | 实际修改品名，下载文件，检查 Excel 单元格和 Word XML 均包含新值 |
| 数学模型编辑后直接求解可能使用旧模型 | 使用当前编辑内容；JSON 错误明确反馈；编辑后旧结果失效 | 示例目标值 2360；系数翻倍后直接求解得到 4720；无效 JSON 不沿用旧结果 |
| 编辑与异步归一化／求解之间存在覆盖风险 | 用模型修改版本检查响应；晚到结果不覆盖新输入，提交阶段防重复 | 检查请求与回调代码；额外执行延迟响应验证 |
| PDF 人工确认取消仍可能提交 | 取消时立即返回；存在未校验字段时先要求重新校验 | 代码检查确认分支 |
| 切换窗口会销毁用户输入 | 保留 iframe，切换时隐藏；Word 版本独立保存步骤 | 切换 Agent、版本和多屏窗口后读取原输入／结果 |
| 刷新容易清掉正在填写的内容 | 重新加载增加明确提示，默认可保留操作 | 实际取消重载，输入不变 |
| 分子量系统嵌入工作台后三列过窄，数值被省略 | 窄窗口允许列换行，并调整指标字号 | 实际计算后检查 Mw 数字无截断，查看工作台截图 |
| 小屏导航只剩颜色点，不便辨识 | 使用带文字的横向 Agent 导航，步骤栏移至系统上方 | 800px、390px 的入口布局检查 |
| 网络／资料请求失败影响整体使用 | 服务状态独立重试；样例加载失败不阻塞 Agent | 拦截状态／样例请求，验证提示与恢复 |
| 不可运行项目容易误解为真实系统 | 标记方案阶段；直接访问操作地址转到方案页 | 页面和深链验证 |

步骤标记只是人工进度，不自动证明业务计算正确。重置标记不会清除应用数据。页面切换保留当前浏览器会话中的 iframe；整页刷新不承诺保留未保存输入。

## 实际界面检查

自动化浏览器按真实按钮操作完成 25 项主流程与回归检查，详情在 `runtime/agent-verification.json`。包括：

- PDF 识别、编辑、Excel / Word 导出；报价缺字段提示。
- 优化示例、参数修改再求解与无效 JSON。
- 配料计算、CSV 导出及修改输入后旧结果失效。
- GPC 默认 Mw 为 55,000.00、复配模式切换。
- 能耗模型切换、旧结果失效、重新训练和数据认知页。
- 操作指引进度、导航保留、多屏切换与展开收起。
- 深链兜底、网络故障恢复、资料允许列表。
- 桌面、800px 平板及 390px 手机入口布局；测试未出现未捕获的浏览器异常。

另人工查看了总览、指引、单据工作台、多屏和响应式截图，修复了窄屏上传顺序和跳转主内容链接的显示／导航问题。

截图位于 `runtime/agent-overview-final.png`、`agent-guide-final.png`、`agent-work-final.png`、`agent-wall-final.png`、`agent-responsive-800.png` 和 `agent-responsive-390.png`。

## 检查边界

本轮验证的是客户引导中的主流程及相关回归，不代表对每个原应用的所有管理功能或全部业务规则做了穷尽验证。未验证云端模型、真实企业微信回调、真实设备接入、公网多用户隔离或 AMD64 镜像。复杂业务表格仍以电脑大窗口操作为主。

业务数据尚未完成脱敏；名称调整和附件入口收敛不能代替数据脱敏。具体风险位置、Docker 数据卷与对外交付包处理建议见 `客户信息脱敏清单.md`。
