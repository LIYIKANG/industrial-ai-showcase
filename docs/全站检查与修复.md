## 已修复的问题

1. **输入变更或失败后残留旧结果**：订单承诺、ATP、排序、齐套和批量检查现在会清理旧结果；异步响应仅在输入版本仍一致时显示。ATP 输入变更后也会禁用旧快照保存。
2. **无效数量与批量漏行**：拒绝非正数；批量清单中有错误时指出具体行，整批不提交，不再静默跳过错误行。
3. **排序参数没有生效**：前端的权重和允许延期参数已接入后端计算。接口测试通过调整权重验证排序次序确实改变。
4. **上传 ATP 文件后仍使用示例数据**：上传接口返回本次解析的数据，前端替换物料、库存、在途、订单、优先级、BOM 和替代料，再计算。齐套也使用对应项目 ID。
5. **关联项目跳转与项目 ID 错配**：加载 ATP 示例不会偷偷改变当前编辑项目的 ID；进入关联视图时读取对应项目的最新数据，计算结果写回正确项目。
6. **化工数学模型为空及数量重复乘算**：关联项目补齐标准模型结构和目标系数；承诺变量按“数量”定义，容量约束不再重复乘订单数量，隔离等式使用标准符号。新增用例验证 100 单位库存可完整承诺 50 单位订单。
7. **保存、导出忽略尚未应用的模型编辑**：保存与导出前先应用并校验当前可见输入，不再导出旧模型。
8. **配料对比保留过期结果**：修改需求、指标、方法或价格输入时移除旧对比；计算中修改输入会丢弃对应的迟到响应。
9. **对比成本单位错误**：总金额改为“料本合计（元）”，单位成本标为“元/kg”。
10. **演示按钮名称误导**：单据模块原“退出登录”实际会重新进入演示，现改为“重新进入演示”，并提示未提交内容会清除。
11. **旧脚本缓存**：求解器和配料脚本更新版本地址；求解器、配料与单据入口/静态资源禁止缓存，避免升级后继续使用旧逻辑。总入口继续使用内容指纹。
12. **样例下载兼容性**：样例库改用明确文件名的 Blob 下载，提供下载中和失败反馈，为内嵌浏览器点击附件链接提供明确反馈。

另外修正了两项测试使用固定 2026-07-02 日期而随时间失效的问题，改为相对当前日期构造业务场景；没有通过修改计算结论绕过测试。

## 界面检查与验证边界

- 检查了桌面总览，以及 390px 手机、800px 平板的总入口布局；总览与操作页没有页面级横向溢出，关键工具按钮位于可视边界内。宽表格可在所在区域横向滚动。
- 本轮浏览器工具可以读取内嵌应用内容，但直接点击跨端口 iframe 时会报告目标不可用。因此业务操作在同一浏览器的各应用独立地址完成，总入口的导航、容器、版本切换和窗口控件单独验证。本轮不把 iframe 内逐按钮点击计为通过。
- 样例下载接口的内容和附件响应头已核对，按钮会给出“已发起下载”反馈；本轮工具未确认两份样例在系统下载目录落盘。业务导出中的 Excel、Word、报告 HTML 和配料 CSV 已核对下载文件。
- 浏览器原生全屏未在本轮工具环境中确认成功；页面内“展开窗口”和多屏“铺满展示”已验证。打印对话框、系统级文件选择和所有表格编辑快捷键没有逐一覆盖。
- 本轮未运行云端大模型、真实企业微信或 PLC/DCS 联调，也未修改真实客户配置或执行生产业务。QA 报价记录和样例任务属于演示数据。
- 客户信息脱敏仍按原清单另行处理；本次功能检查不表示原业务数据已完成脱敏。
- Docker 实测平台为 Linux ARM64；其他操作系统和浏览器不属于本轮覆盖范围。有限测试不能保证不存在其他边界问题。
