# 整合与交互改动

本目录为独立展示副本，未修改桌面原项目。

## 展示中心

- 5 个项目分组；7 个独立进程并行运行，自动分配空闲端口。
- 单入口自动启动、重复启动检查、健康状态、日志查看、单服务重启与整体停止。
- 原系统直接嵌入网页，支持四宫格、单窗口展开、原窗口打开。
- 各项目显示业务出发点、实际能力与可演示结果；无代码的废塑料项目标注为方案。
- 应用 iframe 保持挂载，正常切换项目不会丢失当前输入和计算结果。
- 收录已有 2 段视频，支持页内播放器；未录制新视频。

## 原系统的演示适配

- AI 求解器：将 Cytoscape / ECharts 资源本地化，修复 HTML 中误插入的字面换行符；明确加载样例与求解按钮；改善多标签的换行布局。
- 两套 PDF 系统：保留原界面和业务链，使用独立 SQLite 演示库和本地演示账户；新增样例载入按钮；默认文字层规则解析，顶部明确标注模式；扫描件或不支持的格式显示可理解的错误。
- 商品消息：补齐四种场景样例，改用面向业务的文案；防止计算中通过 Ctrl/Cmd+Enter 重复提交。
- 配料优化：新增 3000 kg / 210 Bloom 演示订单；输入改变后废弃旧结果；求解过程中改变输入时，不再用旧请求覆盖当前结果。
- GPC 分子量：表格变化后废弃旧计算结果，提示重新计算。
- MVR：数据或模型选择变化后，不再展示上一轮误差作为当前模型结果；提示重新训练。

## 验证

已通过浏览器实际操作检查：

1. 7 个服务同时通过健康检查。
2. 5 张项目卡片与业务说明正确展示。
3. 嵌入式 PDF 样例解析与 Excel 下载。
4. PDF 历史版本 Word 下载。
5. 本地优化求解得到示例目标值 2360。
6. 配料样例产生可行方案，输出 3000 kg 用料单并导出 CSV。
7. 修改配料输入后清除旧结果和下载入口。
8. GPC 样例计算 Mw = 55000。
9. MVR 模型切换后提示重新训练，训练后更新图表。
10. 项目切换后保留先前求解结果。
11. 四个 iframe 同时可操作，并完成消息字段校验。
12. 窗口展开和收起正常。
13. 废塑料方案状态明确。
14. 原始操作视频能载入并关闭。
15. 测试过程无未捕获浏览器脚本异常。

另校验生成的 XLSX 工作表、DOCX 内部结构和 CSV 内容，并运行原分子量公式测试。

详细 UI 验证记录在 `runtime/verification.json`；验证脚本为 `scripts/verify_ui.cjs`。脚本需要独立的 Playwright 与 Chrome，日常运行展示中心不需要这些验证依赖。

验证覆盖上述演示路径，并不代表原项目的每个高级功能、任意上传文档或所有模型服务均经过验收。自由文本建模、云端识别与真实企业微信回调还依赖对应模型或账户配置。
