# 企业 AI 成熟度诊断

从桌面 `个人资料/官网` 的 AI Readiness 功能迁入。原网站没有修改；`source-manifest.json` 记录原题库、评分、推荐规则的 SHA-256，便于溯源。

## 文件与运行

- `engine/*.ts`：官网规则的本地副本，仅调整模块导入扩展名和题目数量注释。
- `web/engine/*.js`：预编译的浏览器模块，已随源码及镜像交付。
- `web/flow.js`：必答校验、草稿恢复、痛点追问和报告状态。
- `web/app.js`、`style.css`：客户答题、核对、报告、离线 HTML 下载和打印。
- `showcase_app.py`：提供静态页面及 `/health`，没有接收答卷的接口。

统一入口选择“企业 AI 成熟度诊断 Agent”。Docker 模式子应用端口为 18088，统一入口仍为 18080。原生模式由启动器分配端口。不依赖原官网目录，不需要 Node 运行时、数据库或大模型密钥。

若修改 TypeScript 规则，在已安装 TypeScript 的开发环境执行 `tsc -p projects/maturity/tsconfig.json`，同时提交生成的 JavaScript。规则和流程测试：`node --test projects/maturity/tests/*.test.mjs`。

## 操作与评分

客户选择行业、团队规模及 1–3 个痛点，完成 9 道基础题和每个痛点的 1 道追问，再选择优先场景、核对答卷并生成报告。按钮不会在选择答案后自动跳题。

四维权重：数据 30%、系统 25%、管理 25%、组织 20%。每题 0–3 分，先计算并取整各维得分率，再加权并取整总分。“AI 行动力”是组织维度中两题的单独展示，不额外加权。行业和规模不直接加减分；行业影响参考值。

虚构示例为 49 分，数据 67、系统 44、管理 44、组织 33、AI 行动力 17。规则生成建议和经验参考值不等于实际行业排名、专家现场诊断或收益承诺。

答案只在当前浏览器标签页的 `sessionStorage` 暂存，刷新可继续，关闭标签页后不保证保留。报告下载为独立 HTML，无外链或脚本，可离线打开；打印功能使用浏览器的另存 PDF。共用设备时可清空本次评估；下载文件需自行保管。
