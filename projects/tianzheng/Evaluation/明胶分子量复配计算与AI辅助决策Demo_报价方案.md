# 明胶分子量复配计算与 AI 辅助决策 Demo 系统

## 项目报价与交付方案

**项目名称：** 明胶分子量复配计算与 AI 辅助决策 Demo 系统  
**项目周期：** 约 2 个月（8 周）  
**项目性质：** 第一阶段数字化工艺计算与可视化 Demo；不含机器学习预测模型开发  
**报价口径：** 未税，税费按双方最终合同约定另行核算

---

## 一、项目目标

将明胶生产中已有的分子量、黏度及复配经验公式代码化，形成可演示、可调整、可复核的网页工具。系统用于辅助工艺人员完成 GPC 分子量计算、黏度法估算、胶液复配计算、目标偏差判断和规则式工艺建议，降低人工计算与经验判断的依赖。

本期系统定位为 **工艺计算与辅助决策 Demo**，不承诺替代实验检测或最终质量判定。

---

## 二、总体报价与结算建议

| 项目 | 金额（未税） | 结算节点 |
|---|---:|---|
| 项目启动款 | 108,000 元（30%） | 合同签订后 5 个工作日内支付 |
| Demo 交付款 | 72,000 元（20%） | Demo 开发完成、演示交付并阶段确认后支付 |
| 正式验收款 | 180,000 元（50%） | 试运行优化完成、正式验收通过后支付 |

## 三、阶段一：Demo 开发与演示交付

**周期：** 第 1–4 周  
**阶段费用：** 180,000 元（未税，含启动款 108,000 元及 Demo 交付款 72,000 元）  
**结算条件：** 合同签订后支付启动款；Demo 环境可正常运行，完成演示交付及客户阶段确认后支付 Demo 交付款。

### 1. 建设内容

1. 工艺计算算法底座
   - GPC 分子量计算：Mn、Mw、Mz、PDI；
   - 小分子肽占比计算（分子量小于 10000 Da）；
   - 黏度法 Mw 估算，支持 K、a 参数调整；
   - 多批胶液复配 Mw 计算；
   - 固含量折算的有效干基重量计算；
   - 目标 Mw 偏差、偏差率与合格范围判断。

2. Web 可视化 Demo 页面
   - GPC 分子量计算模式；
   - 黏度法估算模式；
   - 多批次复配计算模式；
   - 批次名称、胶液类型、重量、固含量、Mw 等参数的动态维护；
   - 标准公式可视化展示；
   - 计算结果、偏高/偏低/合格状态及方向箭头展示；
   - 规则引擎式“AI 提问助手”和调配建议。

3. 基础验证与演示资料
   - 公式单元测试与示例测试数据；
   - Demo 启动脚本、依赖清单、运行说明；
   - Demo 演示与操作说明。

### 2. 阶段一交付物

| 类别 | 交付内容 |
|---|---|
| 可运行系统 | 明胶分子量复配计算与 AI 辅助决策 Demo 页面 |
| 源代码 | `app.py`、`calculator.py`、`tests.py` 等完整源代码 |
| 算法说明 | GPC、黏度法、复配及固含量修正公式说明 |
| 测试材料 | 公式测试用例、测试结果与示例数据 |
| 使用材料 | 项目 README、启动脚本、基础操作说明 |
| 阶段汇报 | Demo 演示记录或阶段确认单 |

### 3. 阶段一验收建议

- 系统可在约定电脑或测试环境中正常启动；
- 指定测试案例的计算结果与人工复核结果一致；
- 可录入、修改并动态计算多批胶液参数；
- 可展示目标 Mw、当前 Mw、偏差、偏差率和规则式建议；
- 客户完成 Demo 演示确认。

## 四、阶段二：试运行优化、正式交付与验收

**周期：** 第 5–8 周  
**阶段费用：** 180,000 元（未税）  
**结算条件：** 完成试运行问题整改、正式交付并通过验收后结算。

### 1. 建设内容

1. 试运行支持

2. 范围内优化
   - 修正已确认的公式实现或显示问题；
   - 优化参数默认值、字段名称、提示文案和页面布局；
   - 优化规则式 AI 提问与复配方向建议；
   - 补充双方确认的常规测试数据和操作说明。

3. 正式交付与培训
   - 提供正式版本部署包或源代码包；
   - 完成一次系统使用培训/交接；
   - 提供正式交付清单、验收测试清单和版本说明；
   - 配合完成正式验收。

### 2. 阶段二交付物

| 类别 | 交付内容 |

| 正式版本 | 根据试运行反馈优化后的系统版本 |

| 验收材料 | 验收测试清单、测试结果、问题闭环记录 |
| 使用材料 | 更新后的用户操作手册/培训材料 |
| 交付材料 | 源代码或部署包、版本说明、交付清单 |
| 服务材料 | 培训记录、正式验收单 |

### 3. 阶段二验收建议

- 阶段一功能在正式版本中稳定可用；
- 试运行期间双方确认的问题已完成整改或形成书面处理结论；
- 关键测试数据的计算结果符合已确认公式；
- 客户指定人员可独立完成基础操作；
- 双方签署正式验收单。

## 六、上线后运维服务

**服务费用：** 8,000 元/月（未税）  
**服务起算：** 正式验收后的次月起  
**建议服务周期：** 首签 12 个月，也可按双方合同约定执行。

### 运维服务包含

- 系统运行咨询与远程支持；
- 已交付功能的缺陷修复；
- 页面文案、默认参数、规则提示等轻量级配置调整；
- 月度一次运行情况沟通或问题汇总；

### 运维服务不包含

- 新增机器学习/预测模型开发；
- ERP、MES、LIMS、GPC 仪器或其他第三方系统接口开发；
- 用户、角色、权限、单点登录等企业级账号体系建设；
- 数据库、历史数据治理、报表中心或移动端开发；
- 云服务器、域名、SSL 证书、数据库及第三方软件许可费用；
- 超出本期范围的新页面、新算法、新报表或重大交互改造。

上述新增需求可按人天、按模块或另行项目报价。

## 八、范围边界与变更原则

1. 本期仅实现明确的公式计算、参数调整、可视化展示和规则式辅助建议；不包含真实大模型接入及机器学习模型训练。
2. 系统输出为工艺辅助结果，最终生产投料和质量判定仍由客户工艺及质控人员负责。
3. 因工艺公式调整、新增质量指标、新增数据源、第三方接口或部署架构变化导致的新增工作，双方应书面确认变更范围、工期与费用。
4. 建议将“客户确认的公式版本、测试数据和验收标准”作为合同附件，以避免后续计算口径争议。

## 九、报价结论

本项目建议采用 **“36 万元开发费 + 8,000 元/月运维费”** 的合作方式：

- **10.8 万元（30%）：** 合同签订、项目启动后支付；
- **7.2 万元（20%）：** Demo 开发完成、演示交付并阶段确认后支付；
- **18 万元（50%）：** 试运行优化完成、正式验收后支付；
- **8,000 元/月：** 正式验收后提供持续运维与技术支持。

该方案兼顾客户先看见可运行成果再付款的诉求，也为试运行优化和正式验收预留了明确的工作与结算空间。
