# 01 · 项目概述

## 1.1 业务背景

明胶生产中，每一锅（批）半成品的理化指标都有波动 —— 同一条产线出来的料，冻力可能从 60 到 315
Bloom g 不等。客户下单时给的是一张规格单（目标冻力、水分上限、灰分上限、PH 区间……），
单靠「挑一批合适的料」往往满足不了，需要**把多批料按比例混合**，让加权平均落进规格。

这件事目前靠老师傅的经验和 Excel 手工试算完成，存在三个问题：

| 问题 | 后果 |
|---|---|
| 试算靠手工，只能在少数几批里凑 | 3878 批的库存实际只用到很小一部分，好料被闲置 |
| 无法判断「配不出来」是暂时的还是根本不可能 | 反复试算浪费时间，最后仍要回头找客户谈放宽 |
| 多张订单分别试算 | 两张单可能同时把同一批料算进自己的方案，到车间才发现料不够 |

## 1.2 项目目标

把配料从「经验试算」变成「一次求解」：

1. **全库存参与** —— 3878 批全部进入候选，不再局限于手工能顾及的范围
2. **全局最优** —— 用混合整数线性规划求解，不是启发式凑数
3. **多单协同** —— 多个目标一次性求解，从建模上杜绝重复分配
4. **可行性诊断** —— 配不出来时明确告知是哪项指标超出了库存的可达区间

## 1.3 功能范围

### 已实现

- 库存数据浏览：12 项指标全量展示，排序 / 区间筛选 / 分页 / 指标分布统计
- 配料求解：多目标输入，逐单给出用料单（批号 + 取用公斤数 + 占比）与规格达成情况
- 参数管理：9 项指标的上下限设定、启用开关、求解参数配置，落盘持久化
- 结果导出：按单导出 CSV（带 BOM，Excel 直接打开不乱码）
- 可行性预检：目标超出库存可达区间时直接给出原因，不让用户干等求解器
- 数据热更新：源 Excel 更新后点「重新导入」即可，无需重启服务
- 数据看板：接单能力曲线、冻力分布、指标余量、分段构成、等级构成
- 方案对比：对照组（模拟人工）+ 四种优化目标横向评估，含权衡前沿与 CSV 导出

### 不在本期范围

- 用户体系与权限（当前单机单用户）
- 配料方案的历史留档与审批流
- 与 MES / ERP 的对接
- 库存的实时扣减（当前每次求解都基于全量库存快照）

## 1.4 术语表

| 术语 | 含义 |
|---|---|
| **批 / 批次** | 一锅半成品，源表的一行，有唯一的「数据编号」 |
| **冻力 (Bloom)** | 明胶最核心的指标，衡量凝胶强度，单位 Bloom g。客户规格的主项 |
| **配料 / 掺混 (blending)** | 把多批料按比例混合，使加权平均指标达到目标 |
| **加权平均** | 以取用重量为权重的平均值，`Σ(取用量 × 指标) / Σ取用量` |
| **容差** | 目标值允许的偏差范围，如冻力 210 ± 5 |
| **上下限** | 非目标指标需要落入的区间，如水分 8 ~ 14% |
| **候选池** | 通过等级过滤和缺失值过滤后，允许参与配料的批次集合 |
| **预筛 (candidates)** | 每张订单按冻力接近程度从候选池里取最近的 N 批建模，控制求解规模 |
| **MILP** | 混合整数线性规划，本系统的求解方法 |
| **可达区间** | 库存中某指标的 [最小值, 最大值]。加权平均永远落在其中，目标超出即无解 |

## 1.5 关键设计取舍

### 为什么目标值要分方向

客户规格单上写的是「冻力 ≥ 210」「水分 ≤ 12%」，不是「冻力 = 210 ± 5」。
方向是规格的一部分：**冻力配低了整批不合格，配高了客户不会退货**。

所以每项目标都带一个方向（`≥` / `±` / `≤`），默认按各指标的物理意义预设，可逐单调整。

### 为什么还要保留「上下限区间」

规格单上没写明的指标也不能不管 —— 它们只要不超出常规范围即可，
逼用户为每一项编一个假目标值没有意义。两套机制分工：

| 机制 | 用于 | 设置位置 |
|---|---|---|
| 目标值 + 方向 + 容差 | 规格单上写明的项 | 配料页，逐单设定 |
| 上下限区间 | 其余项的兜底 | 参数设定页，全局设定 |

同一指标可以同时有两者，取交集。

### 为什么要有「取料偏好」

高冻力料稀缺（全库存冻力 ≥300 的只有 5 批）且能做高牌号产品。
配一张 210 的单时，用 205+215 的中间料和用 60+315 的两头料都能达标，
但后者白白啃掉了高端库存。

反过来，有时车间希望清掉积压的低冻力料，就要主动用两头料。
这个取舍是业务判断，不该由求解器替用户做 —— 所以做成逐单可选的偏好。

### 为什么水不溶物不参与加权平均

它是文本等级（1级 / 2级 / 3级 / 4级），不是连续量，加权平均没有物理意义。
系统改为**硬过滤**：差于设定等级的批次直接排除在候选池外。

### 为什么目标函数首先最小化批次数

每多用一批料，车间就多一次投料、清洗、转运和记录。在都能达标的方案里，
批次少的那个实际成本明显更低。居中程度作为次级目标，只在批次数相同时起作用。
