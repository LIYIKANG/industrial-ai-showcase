# 06 · 数据说明

## 6.1 源数据

- 文件：`副本AI 测试模拟数据-20260805(1).xlsx`（位于项目上级目录）
- 工作表：`Sheet1`（Sheet2 / Sheet3 为空）
- 原始规模：4057 行 × 47 列

## 6.2 四个必须绕开的坑

源表是从生产系统导出后人工加工过的，直接 `read_excel` 会得到一张废表。
以下四点在 `app/data.py` 里逐一处理。

### 坑一：表头在第 2 行

| Excel 行 | 内容 |
|---|---|
| 第 1 行 | 大标题 `AI测试模拟数据`，合并单元格 A1:L1 |
| **第 2 行** | **真正的表头** |
| 第 3 行起 | 数据 |

默认读法会把大标题当表头，整表报废。
处理：`has_header=False` 整表读入，手动取索引 1 的行作列名。

### 坑二：列名重复

`大肠发酵` / `沙门发酵` / `大肠疑似` / `沙门疑似` 在 A~X 和 Y~AP 各出现一次。
重名会让 DataFrame 直接建不出来。

处理：第 2 次出现的加 `__2` 后缀。

### 坑三：尾部 177 行是假空行

行 3880~4057 的 A~X 全空，但辅助公式列对空行算出一串 `0`。

如果按「整行全空」判断，**一行都删不掉** —— 因为辅助列有值。
必须只看核心指标列来判断。

处理：只对 `PARAM_KEYS` 做全空判断。有效数据从 4055 降到 **3878 条**。

> 这个坑最隐蔽：不处理的话缺失率、均值、计数全部被拉偏，而且看不出任何异常。

### 坑四：混合类型

| 列 | 实际取值 |
|---|---|
| 菌落总数 | `<10`、`10`、`TNTC` |
| 水不溶物 | `2级`、`3级` |
| 大肠杆菌 | `未检出`、`检出` |
| 合格 / 月份 / pi | 整列 `#REF!`（公式引用已断） |

自动类型推断会把整列吃成 null。

处理：**先整表按字符串读入**（`read_options={"dtypes": "string"}`），
再按 `config.PARAMS` 的定义显式转换，`strict=False` 让转不了的值变 null 而不中断。

水不溶物等级分布：`2级 × 2223`、`3级 × 1554`、`4级 × 94`、`1级 × 7`。

### 需要注意的产能约束

**PH 值几乎顶到库存上限。** 中位数 5.68，p99 = 5.97，最大 6.09 ——
全库存 PH ≥ 6.0 的只有 **19 批**。

由于加权平均永远落在参与批次的极值之间，客户若要 PH 6.0 的硬指标，
必须几乎全部使用那 19 批，量根本不够。**这不是算法能解决的问题**，需要工艺端调整。

灰分同理偏紧：≤ 0.25 的只有 794 批。

## 6.5 被丢弃的数据

清洗时丢掉的内容及理由：

| 内容 | 理由 |
|---|---|
| 微生物指标（菌落总数、霉菌、大肠杆菌、沙门氏菌等 10 列） | 不参与配料计算。本期范围内客户规格只涉及理化指标 |
| 辅助计算列 Y~AP（Bloom、viscosity、T450 等 15 列） | 原表的中间乘积，公式已失效 |
| `合格` / `月份` / `pi` 三列 | 整列 `#REF!`，读入后全 null |
| 尾部 177 行 | 假空行，见坑三 |
| 重量为空或 ≤ 0 的批次 | 无法参与配料 |

> 若后续需要把微生物指标纳入约束（例如客户要求菌落总数上限），
> 注意它们是**删失数据**（`<10` 表示低于检出限），不能简单当数值用。
> 建议拆成「数值 + 算符」两列，`算符 == "<"` 的按左删失处理。

## 6.6 缓存机制

```
Excel 源  →  清洗  →  data/inventory.parquet  →  进程内存
```

- 首次启动读 Excel（约 2 秒），之后读 parquet（毫秒级）
- parquet 损坏会自动回退读 Excel 重建，不影响服务启动
- 源 Excel 更新后，在库存页点「**重新导入**」穿透缓存重新读取

## 6.7 更换数据源

改 `app/config.py`：

```python
SOURCE_XLSX = PROJECT_ROOT / "你的新文件.xlsx"
SOURCE_SHEET = "Sheet1"
HEADER_ROW_INDEX = 1   # 0-based，表头在第几行
```

新表的列名需要能对上 `config.PARAMS` 里的 `key`（清洗会自动去掉换行和空格）。
对不上时启动会报错并列出实际列名，照着改 `PARAMS` 即可。
